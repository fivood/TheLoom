# OneDrive 同步设置

> **当前已隐藏(2026-08-27)。** 界面上没有「存放位置」下拉,只有 S3 兼容存储。
> 挡住的不是代码,是微软那边:个人微软账号落在「Microsoft Services」伪租户里,
> 那里禁用应用注册,要用就得先自建一个 Entra 租户。
> 恢复方法:把 `src/components/RemotePanel.tsx` 里的 `ONEDRIVE_ENABLED` 改回 `true`。

外链网盘同步支持两种后端:S3 兼容存储(R2 / B2 / MinIO / OSS)与 OneDrive。
两者共用同一套端到端加密与冲突判定,区别只在文件存在哪。

OneDrive 走 Microsoft Graph,权限只申请 `Files.ReadWrite.AppFolder` ——
数据写在 OneDrive 的「应用/TheLoom」文件夹下,应用碰不到你的其他文件。

## 一次性:注册一个 Azure 应用

应用 ID 不是密钥,可以公开;注册免费,不需要 Azure 订阅。

1. 打开 <https://portal.azure.com> → 搜索并进入「应用注册」→「新注册」
2. 名称随便填(如 `TheLoom`)
3. **受支持的帐户类型**选「任何组织目录中的帐户和个人 Microsoft 帐户」
   —— 个人 OneDrive 属于后者,只选前者会登录不上
4. **重定向 URI**:平台必须选 **单页应用程序(SPA)**,填你实际访问本应用的地址,
   末尾带斜杠:
   - 线上:`https://<你的域名>/`
   - 本地开发:`http://localhost:5273/`

   平台选错(比如选成「Web」)会导致换令牌那一步被 CORS 拦掉,
   现象是登录跳转正常、回来却报网络错误。同一个应用可以加多个 SPA 重定向 URI。
5. 注册完成后,在「概述」页复制 **应用程序(客户端)ID**

## 在应用里连接

工具菜单 →「外链网盘同步」:

1. 「存放位置」选 **OneDrive**
2. 粘贴刚才的应用 ID
3. 点「登录 OneDrive」,授权后会跳回本应用
4. 填「加密口令」——**口令丢了数据不可恢复**,网盘里只有密文
5. 「上传」把当前项目推上去;另一台设备同样配置后「拉取」
6. 需要的话勾上「自动同步」

每台设备都要单独登录一次并填同一个口令。口令与「后端 + 路径」共同派生密钥,
换后端或改路径后,要用同一口令才能解开原有数据。

## 自动同步

勾选后:

- **停手 30 秒**自动上传一次(两次自动上传之间至少隔 60 秒)
- **回到窗口时**查一次远端,有更新弹提示

**只自动上传,不自动替换**。上传是加内容,冲突有 ETag 挡着;拉取是整份替换当前项目,
必须由人点头,所以远端有更新时只提示,拉取仍要你点。

自动同步**绑定开启时的那部作品**。远端只存一个项目对象,换个槽位还自动推的话会
把另一本盖掉,所以换作品后自动上传就停了,需要在新作品里重新勾一次。

撞上冲突(别的设备先推了)会暂停自动上传并提示,在面板里拉取或强制覆盖之后恢复。

## 已知限制

- **令牌会过期**。浏览器端 OAuth 的 refresh token 只有 24 小时,Safari 拦第三方
  cookie 后静默续期常常失败,所以隔一段时间需要重新点一次「登录 OneDrive」。
  S3 密钥不过期 —— 嫌烦就用 S3 后端。
- **桌面版(Tauri)请用文件夹模式**。桌面端的 origin 不是 http(s),没法注册成
  SPA 重定向 URI;把项目文件夹放进本地 OneDrive 目录即可,那条路已经实测过。
- **切换后端 = 换仓库**。S3 里的项目不会自动搬到 OneDrive,切过去后要重新上传一次。
- 远端只存**一个**项目对象,对应当前打开的槽位;换一部作品再上传会覆盖远端。

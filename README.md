# TheLoom 叙事织机

面向写作者与叙事设计师的本地优先创作工具,用于构建分支叙事、管理故事设定与组织写作前期资料。
结构化叙事方法参考 articy:draft,并结合表格式大纲、故事时间线与资料卡片归档等写作方法论。

网页版与 Windows 桌面版(Tauri),黑白灰界面(浅色 / 深色),**所有数据默认保存在本地**。

> 功能的完整说明在应用内:按 <kbd>F1</kbd> 或「工具 → 使用指南」。本文只做概览。

## 模块

| 模块 | 做什么 |
|---|---|
| **流程** | 节点式分支叙事。对白 / 片段 / 汇聚点 / 条件 / 指令 / 检定 / 跨流程调用 / 外部事件;子流程可无限嵌套 |
| **文档** | 长篇写作台。卷章树、三视图(写作 / 结构 / 连续稿)、专注模式、批注与快照 |
| **设定集** | 角色 / 地点 / 物品 / 阵营 / 设定,自定义字段与模板;技术名可被脚本寻址 |
| **资源** | 图片音视频与文件,按内容哈希存放去重 |
| **资料** | 考据与灵感卡片,分类 / 标签 / 全文搜索 |
| **规划** | 关系图、角色弧线、伏笔台账、登场统计、卡片墙、节奏图、写作进度、修订 |
| **大纲** | 罗琳式表格:行 = 章,列 = 剧情线 |
| **时间线** | 轨道 × 时间点矩阵,事件可关联实体与场景 |
| **地图** | 标记 / 区域 / 矢量形状 / 图层,可按时间点筛选;不需要底图也能用 |
| **风暴** | 便签自由画布,可转成场景或大纲行 |
| **变量** | 布尔 / 数值 / 文本,供流程条件与指令读写 |

## 特点

- **文档与流程共享同一份内容**:同一段对白在两边编辑都会同步,不存在两个副本各写各的
- **自有脚本语言**:不动态执行字符串;条件与指令有词法分析、类型检查与精确到字符的错误定位,改名时全项目脚本自动跟随
- **体检**:孤儿节点、分支缺口、未定义变量、跨模块无效引用、路径不可达与死循环,点问题直达出错处
- **文件夹模式**:桌面版可把项目绑定到本地目录,正文就是带 frontmatter 的 Markdown,**Obsidian 可直接读写**
- **引擎导出**:带 JSON Schema 的引擎包 + 零依赖运行库,TypeScript / Godot / C# 三端同种子输出一致
- **稿件互通**:导入 TXT / Markdown / EPUB / DOCX;导出 DOCX 成稿、Final Draft、章节编译

## 数据与同步

数据默认只在本机:网页版存浏览器,桌面版可存浏览器或本地文件夹。两条同步路径可同时用:

- **文件夹 + 云盘**(电脑之间):项目目录放进 OneDrive / Dropbox,云盘负责同步,Obsidian 共用同一份文件
- **外链网盘**(手机 ↔ 电脑):同步到你自己的 S3 兼容存储(Cloudflare R2 / Backblaze B2 / MinIO / 阿里云 OSS)。
  按作品分目录、逐文件增量、只自动上传不自动替换。**这是手机与电脑之间唯一的通道** —— 手机上碰不到本地文件夹

写入采用「写临时文件 → 替换」的原子替换,保留 `.bak`;每次保存留自动恢复点,存档损坏会被隔离并给出诊断导出。

## AI(可选)

默认关闭。启用后模型只有白名单只读工具,输出必须先在项目副本上通过脚本类型检查、引用校验、
体检与路径测试,用户确认后才作为一次 `commit` 写入,可 Ctrl+Z 整体回滚。

API Key 只存本机(网页版 localStorage / 桌面版 Windows 凭据管理器),不写入项目、不参与同步、
不出现在诊断导出。可切换 OpenAI 兼容 / Anthropic / Ollama 本地模型。

## 音视频的定位

TheLoom 专注文本流程。**音视频在这里是「挂接物」,不是播放对象**:你把它挂到节点或实体上,
TheLoom 记录这份对应关系并在导出时交给引擎,**实际播放由引擎负责**。资源库里的试听 / 试看
只是为了确认挂对了文件。
